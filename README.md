# MOP 파티룸 웹사이트

대구 파티룸 MOP 소개·예약 안내용 원페이지 사이트입니다. 빌드 없이 정적 파일만으로 동작합니다.

## 구조

```
index.html     페이지 본문 (공간 소개, 요금, 이용안내, 예약, 오시는 길, FAQ)
css/style.css  스타일
js/main.js     모바일 메뉴, 플로팅 예약 버튼
images/        사진 넣는 폴더 (og.jpg = 링크 공유 썸네일, 1200x630 권장)
```

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 채워야 할 정보

`index.html`에서 `TODO` 주석과 `[대괄호]` 부분을 실제 값으로 바꾸면 됩니다.

- 주소, 가까운 역·출구, 주차 안내, 전화번호
- 타임별 이용 시간과 평일/주말 요금, 기준·최대 인원, 추가 요금
- 주류 반입, 반려동물 동반 여부, 환불 규정
- 네이버 예약 / 카카오톡 채널 / 인스타그램 링크
- 공간 사진 (갤러리의 `.ph` 박스를 `<img src="images/파일명.jpg" alt="설명">`로 교체)
- 지도: 네이버 지도 또는 카카오맵 "공유 → 지도 퍼가기" iframe을 `.map` 안에 붙여넣기
- 사업자 정보 (푸터)
- 도메인: `canonical`, `og:url`, JSON-LD의 `url` 값
- JSON-LD(LocalBusiness)의 전화번호·주소

## 배포 후

- 네이버 서치어드바이저에 사이트 등록 → `naver-site-verification` 메타 태그 주석 해제 후 코드 입력
- 네이버 스마트플레이스에 업체 등록 후 홈페이지 URL 연결
