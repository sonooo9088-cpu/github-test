# MOP 파티룸 웹사이트

대구 파티룸 MOP 소개·예약 안내용 원페이지 사이트입니다. 빌드 없이 정적 파일만으로 동작합니다.

## 구조

```
index.html     페이지 본문 (공간 소개, 요금, 이용안내, 예약, 오시는 길, FAQ)
css/style.css  스타일
js/main.js     모바일 메뉴, 플로팅 예약 버튼
images/        사진 넣는 폴더 (og.jpg = 링크 공유 썸네일, 1200x630 권장)
```

## 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 채워야 할 정보

`index.html`에서 `TODO` 주석과 `[대괄호]` 부분을 실제 값으로 바꾸면 됩니다.

- 주소, 가까운 역·출구, 주차 안내, 전화번호
- 타임별 이용 시간과 평일/주말 요금, 기준·최대 인원, 추가 요금
- 주류 반입, 반려동물 동반 여부, 환불 규정
- 네이버 예약 / 카카오톡 채널 / 인스타그램 링크
- 공간 사진 (갤러리의 `.ph` 박스를 `<img src="images/파일명.jpg" alt="설명">`로 교체)
- 지도: `images/map.jpg` 약도 이미지 + 네이버지도·카카오맵 공유 링크
- 사업자 정보 (푸터)
- 도메인: `canonical`, `og:url`, JSON-LD의 `url` 값
- JSON-LD(LocalBusiness)의 전화번호·주소

## 운영 구조 (월 고정비 0원)

| 역할 | 서비스 | 비용 |
|---|---|---|
| 홈페이지 호스팅 | GitHub Pages (이 저장소) | 무료 (공개 저장소 기준) |
| 예약 | 네이버 예약 (스마트플레이스) | 무료, 네이버페이 결제 연동 시에만 결제 수수료 |
| 문의 | 카카오톡 채널 | 기본 채팅 무료 |
| 지도 | 약도 이미지 + 네이버지도·카카오맵 링크 | 무료 |
| 도메인 (선택) | 가비아, Cloudflare 등 | 연 단위 결제 |

서버가 없는 정적 사이트라 예약·결제·지도 같은 기능은 외부 서비스 링크로 연결합니다.

## GitHub Pages로 공개하기

1. 저장소 Settings → Pages
2. Source: Deploy from a branch → 배포할 브랜치, 폴더 `/ (root)` 선택 → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 주소로 접속
4. 도메인이 있으면 같은 화면의 Custom domain에 입력하고, 도메인 업체 DNS에 GitHub Pages 설정 추가

## 내용 수정하기

코드 도구 없이 GitHub 웹에서 바로 고칠 수 있습니다.

1. 저장소에서 `index.html` 클릭 → 연필 아이콘(Edit)
2. 요금·문구 수정 → Commit changes
3. 1~2분 뒤 사이트에 반영

사진은 `images` 폴더에서 Add file → Upload files로 올립니다. 한 장당 500KB 이하로 줄여서 올리면 모바일에서 빨리 뜹니다.

## 배포 후

- 네이버 서치어드바이저에 사이트 등록 → `naver-site-verification` 메타 태그 주석 해제 후 코드 입력
- 네이버 스마트플레이스에 업체 등록 후 홈페이지 URL 연결
